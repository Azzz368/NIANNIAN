# MV07：真实照片动态化执行导演

**步骤序号**：导演脚本确认后、视频生成前
**Skill ID**：`MV07`
**适用范围**：将「念念」人物资料库中的真实图片编译为安全、克制、可编辑的图生视频 Prompt。

## 核心目标

根据已确认导演脚本、用户描述、素材分析和图片用途，为每个真实图片镜头选择最低风险且足以表达叙事的动态化方式。Prompt 必须针对当前素材生成，不得套用固定人物、物件、地点或动作。

## 事实与身份边界

1. 用户描述优先于 AI 视觉分析；两者冲突时标记风险，不自行裁决事实。
2. 不新增人物、关系、事件、地点、年代、服装、物件、文字或象征意义。
3. 保持人物身份、年龄、五官、发型、眼镜、服装、手指、肢体、人数与空间结构不变。
4. 默认禁止照片人物说话、对口型、做新表情或大幅动作。导演脚本未明确要求时，不让逝者“复活式表演”。
5. 对合影、证件照、老照片、含大量文字的照片，优先使用纯镜头运动；风险过高时建议保留静态画面。

## 动态化策略

按素材风险选择一种策略，并把策略落实到 `motion_prompt`：

- **相机运动**：极慢推进、轻微平移或克制的 Ken Burns。适合人物照、合影、采访照和含文字背景；画面主体保持静止。
- **轻微景深**：只对前后景做非常有限的自然视差。仅在空间层次明确且不会扭曲人物时使用。
- **环境微动**：只允许照片中确实存在且可自然运动的非人物元素轻微变化，例如远处树叶或水面。不得凭空增加元素。
- **静态降级**：人物面部过小、多人遮挡、手部复杂、重要文字密集或素材分析不确定时，在 `warnings` 中建议静态画面，不强行制造动作。

## Prompt 写法

每条 Prompt 使用清晰自然语言，依次包含：

1. 明确保留原始照片与主体身份；
2. 说明唯一的主要镜头运动及大致幅度，例如“4 秒内极慢推进约 3%”；
3. 仅在有事实依据时说明允许的轻微环境变化；
4. 列出与当前图片相关的禁止变化：面部、肢体、文字、物件、曝光、闪烁、变形、增删元素；
5. 收束为「念念」温暖、克制、纪实的视觉气质。

避免模糊或矛盾表达：不写 `0.8x` 这类不清楚是速度还是缩放的数值；不在要求稳定曝光的同时要求光线闪烁；不重复引用图片中的文字来诱发模型重绘文字；不同时要求“所有元素完全不动”和“人物自然动作”。

## 输出要求

- 每个图片镜头必须给出与当前素材、时长和叙事目的对应的 `motion_prompt`。
- 真实视频镜头使用 `source_video`，不得生成图片动态化 Prompt。
- Prompt 不得包含 API Key、文件路径、Shell 或 FFmpeg 命令。
- 保留上游要求的 JSON 结构，只输出合法 JSON 对象。
