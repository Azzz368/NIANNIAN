# 念念追思影像平台 — 主分支重构指导文档

> **用途**：基于 `backup` 分支已完成的前后端分离重构经验，指导 `main` 分支进行相同方向的项目结构优化。  
> **核心策略**：保留 Streamlit 作为可选的内部运营/调试界面，同时建立 FastAPI 作为正式 API 服务层，Vanilla JS 作为用户前端。

## 三、关键重构原则

### 3.1 分层架构（严格遵守）

```
前端 (HTML/JS)
    ↓  HTTP (JSON)
FastAPI routers/        ← 只处理请求解析和响应序列化，不含业务逻辑
    ↓  函数调用
services/service_manager.py   ← 唯一入口，routers 禁止直接 import 具体模块
    ↓
services/*.py           ← 具体业务逻辑（LLM/ComfyUI/视频/门控）
```

**黄金规则**：routers 层只能 `from services import service_manager`，绝不直接 `from services.llm_client import ...`

### 3.2 gate_manager 去 Streamlit 化

原 `gate_manager.py` 使用 `st.session_state`，迁移时必须替换为模块级字典：

```python
# ❌ 旧写法（Streamlit 依赖）
import streamlit as st
st.session_state["gate_mv02"] = True

# ✅ 新写法（纯 Python，无框架依赖）
_gate_status: dict = {}
_gate_rejections: dict = {}

def check_gate(step: str) -> bool:
    return _gate_status.get(step, False)

def open_gate(step: str) -> None:
    _gate_status[step] = True
```

### 3.3 pipeline_runner 导入修改

迁移到 `backend/services/` 后，所有裸导入需加 `services.` 前缀：

```python
# ❌ 旧写法
from gate_manager import check_gate
from skill_loader import load_skill

# ✅ 新写法
from services.gate_manager import check_gate
from services.skill_loader import load_skill
```

同时修改基础路径：
```python
# 旧：相对于根目录
BASE_DIR = Path(__file__).resolve().parent

# 新：相对于 backend/
BASE_DIR = Path(__file__).resolve().parent.parent
```

### 3.4 Streamlit pages/ 的定位

`pages/` 内的 Streamlit 页面**继续保留并可独立运行**，但职责收窄为：
- **内部运营工具**：查看 pipeline 状态、手动触发步骤、素材管理
- **调试界面**：开发阶段快速验证 LLM 输出
- **不承担用户交互**：正式用户流程全部由 `frontend/` + FastAPI 处理

Streamlit 启动命令（与 FastAPI 并行运行）：
```bash
# 终端1：FastAPI
cd backend && uvicorn main:app --reload --port 8000

# 终端2：Streamlit（可选，内部用）
streamlit run app.py --server.port 8501
```

## 四、API 接口规范

### 基础信息
- Base URL：`http://localhost:8000/api`
- 数据格式：JSON
- CORS：开发阶段 `allow_origins=["*"]`，生产收紧到具体域名

### 接口一览

| 方法 | 路径 | 功能 |
|------|------|------|
| POST | `/intake/submit` | 提交表单，返回 `session_id` |
| GET  | `/intake/test-data` | 获取测试用人物数据（陈建国） |
| POST | `/chat/greeting` | 获取 AI 开场白 |
| POST | `/chat/message` | 发送对话消息 |
| POST | `/chat/generate-json` | 对话结束，生成结构化 JSON |
| GET  | `/chat/preview/{session_id}` | 获取生平预览文本 |
| POST | `/pipeline/run/{step}` | 执行 MV01-MV06 某步骤 |
| GET  | `/pipeline/status/{session_id}` | 查询 pipeline 执行状态 |
| POST | `/assets/upload` | 上传照片/视频素材 |
| GET  | `/assets/background` | 获取默认背景图（base64） |

### Session 结构（内存存储）
```python
{
    "session_id": "uuid4",
    "form_data": { ... },          # intake 表单数据
    "assets": [ "path/to/img" ],   # 已上传素材路径
    "chat_history": [ {...} ],     # 对话记录
    "mv01_json": { ... },          # MV01 结构化输出
    "preview_text": "..."          # 生平预览文本
}
```

## 五、前端核心设计

### api.js（统一封装）
```javascript
const API_BASE = 'http://localhost:8000/api';

async function apiPost(path, body) { ... }
async function apiGet(path) { ... }
async function apiUpload(path, formData) { ... }
```

### memorial.js 流程（3步）
1. **Step 1**：表单填写（基本信息）→ `POST /intake/submit` → 存 `sessionId`
2. **Step 2**：AI 对话补充记忆 → `POST /chat/greeting` + `POST /chat/message`
3. **Step 3**：预览 + 触发 Pipeline → `GET /chat/preview` + `POST /pipeline/run/MV01`

### 测试数据快捷键
点击「测试数据」按钮 → `GET /intake/test-data` → `fillForm(data)` 自动填充所有字段并跳至 Step 2。

## 六、重构执行步骤（推荐顺序）

```
Step 1  创建目录结构
        mkdir backend/routers backend/services backend/skills backend/outputs/uploads backend/outputs/final_cuts
        mkdir frontend/css frontend/js frontend/assets
        mkdir archive

Step 2  迁移服务层
        cp llm_client.py      → backend/services/llm_client.py
        cp gate_manager.py    → backend/services/gate_manager.py   ★ 去除 st.session_state
        cp pipeline_runner.py → backend/services/pipeline_runner.py ★ 修改 import 前缀 + BASE_DIR
        cp skill_loader.py    → backend/services/skill_loader.py
        cp comfyui_client.py  → backend/services/comfyui_client.py
        cp video_editor.py    → backend/services/video_editor.py

Step 3  新建 service_manager.py
        统一 re-export 所有 services，routers 只从此处 import

Step 4  新建 FastAPI 主程序
        backend/main.py（注册4个router，配置CORS）

Step 5  新建 routers/
        intake.py / chat.py / pipeline.py / assets.py
        每个 router 只做：解析参数 → 调用 service_manager → 返回结果

Step 6  新建 frontend/
        index.html / memorial.html / dialogue.html
        css/style.css
        js/api.js / memorial.js / home.js / dialogue.js

Step 7  归档旧文件
        mv app.py app_backup*.py write_pipeline.py test_i2v.py → archive/

Step 8  测试验证
        cd backend && uvicorn main:app --reload --port 8000
        curl http://localhost:8000/api/intake/test-data
```
