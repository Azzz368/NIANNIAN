## 二、运行方式

### 方式 A：用户端（FastAPI + Vanilla 前端）

```powershell
# 安装后端依赖（仅首次）
pip install -r backend/requirements.txt

# 启动
.\start_backend.ps1
```

访问：
- **主程序入口**：http://localhost:8000/  （首页，自动跳转）
- 念念影像制作：http://localhost:8000/memorial
- AI 深度搜索：http://localhost:8000/deep_search
- API 文档：http://localhost:8000/docs
- 健康检查：http://localhost:8000/api/health

### 方式 B：内部调试（Streamlit，保持原样）

```powershell
.\start_streamlit.ps1
```

访问 http://localhost:8501

### 方式 C：两者并行（推荐开发模式）

两个 PowerShell 终端分别运行上述两个脚本，互不冲突。Session 不共享，分别独立。

## 四、分层架构

```
┌───────────────────────────────────────────┐
│ frontend/ (HTML/JS)   |   pages/* (Streamlit)│
└────────┬──────────────────────┬─────────────┘
         │ HTTP/JSON            │ direct import
         ▼                      ▼
┌─────────────────────┐   ┌──────────────────┐
│ backend/routers/    │   │  (Streamlit 直调) │
│ (薄层，只解析请求)   │   │                  │
└────────┬────────────┘   └────────┬─────────┘
         │ function call            │
         ▼                          ▼
┌────────────────────────────────────────────┐
│        backend/services/service_manager     │
│        + 根目录 llm_client / skill_loader   │
│        ← 业务逻辑层，框架无关                │
└────────────────────────────────────────────┘
                │
                ▼
┌────────────────────────────────────────────┐
│   302.ai 网关 / 可灵 / ComfyUI / Whisper    │
└────────────────────────────────────────────┘
```

**复用策略**：`backend/services/__init__.py` 自动将项目根加入 `sys.path`，因此 `service_manager.py` 直接 `from llm_client import ...`，**与 Streamlit 共享同一份代码**。修改一次，两端同步生效。

## 五、关键设计点

### 5.1 Session 隔离

Streamlit 端使用 `st.session_state`；FastAPI 端使用内存 `session_store`（线程安全 `RLock`）。两边互不影响。生产环境可将 `session_store` 替换为 Redis。

### 5.2 门控（Gate）去 Streamlit 化

原 `gate_manager.py` 重写为 `backend/services/gate_manager.py`，所有函数接收 `state` dict 作为首参（无任何全局/框架依赖）。Streamlit 端旧版继续保留。

### 5.3 深度搜索复用

`service_manager.deep_search()` 与 `pages/deep_search.py` 共用同一套提示词和模型策略：
- 优先：`perplexity/sonar-pro` → `perplexity/sonar` → `gpt-4o-search-preview`
- 降级：`claude-sonnet-4-6` → `gpt-5.4`（知识库模式，加注）

### 5.4 跨端 Session 桥接（可选未来扩展）

目前 Streamlit 与 FastAPI session 独立。若需打通，可让 Streamlit 在创建 session 后调用 `session_store.create_session()` 并将 sid 写入 cookie / URL。
